# Правила для разработки

- Система только читает Telegram-каналы через Telethon и отправляет карточки владельцу через aiogram.
- Не добавлять автоотклики, отправку сообщений в каналы, реакции, автоподписки, RSS, биржи, сайты, браузерную автоматизацию, OpenAI API или платные API без явного запроса.
- Секреты только в `.env`; никогда не добавлять его в репозиторий и не логировать значения.
- Перед изменением фильтра расширять тесты в `tests/test_filters.py`.
- Не запускать `authorize_telegram.py` без явного участия владельца аккаунта.
